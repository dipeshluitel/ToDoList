# ✅ ToDoList — A Simple Django To-Do Web App

A clean and functional **To-Do list web application** built using **Django**, where users can create, update, complete, and delete daily tasks.  
This project demonstrates core Django concepts such as models, views, templates, and URL routing, making it an excellent learning and portfolio project.

---

## 🚀 Features

- ➕ Add new tasks easily  
- ✅ Mark tasks as complete/incomplete  
- 🗑️ Delete tasks  
- ✏️ Edit existing tasks  
- 🧭 Simple and responsive user interface  
- 💾 SQLite database support  


---

## 🧰 Tech Stack

| Layer | Technology |
|--------|-------------|
| **Frontend** | HTML, CSS, Bootstrap |
| **Backend** | Django (Python) |
| **Database** | SQLite |
| **Deployment** | PythonAnywhere |
